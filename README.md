# Electricity Calculator

## Description
This program calculates the electricity bill/cost based on consumption.

## Version 1 Original code without input validation
- Input: Accepts user inputs for electricity usage.
- Process: Calculates the total electricity cost.
- Output: Displays the total computed cost.
- Does not include input validation.

## Version 2 Code with input validation
- Input: Accepts user inputs for customer name, previous meter reading, and current meter reading.
- Process: Validates that the customer name is not empty, the previous reading is a valid number at least 0 and the current reading is a valid number greater than or equal to the  previous reading. Then computes the consumption and total bill.
- Output: Displays the validated customer name, electricity consuption, and the total  computed bill.
- Includes input validation.
